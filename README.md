# Sprint 1 - Estruturação Inicial do Backend

Nesta sprint foi realizada a configuração inicial da API backend utilizando Node.js e Express, preparando o ambiente para desenvolvimento das funcionalidades do sistema.

---

## Objetivos da Sprint

- Estruturar ambiente backend
- Configurar servidor Express
- Implementar rota inicial de teste
- Preparar ambiente para desenvolvimento escalável
- Organizar arquitetura inicial do projeto

---

## Tecnologias Utilizadas

- Node.js
- Express
- Nodemon
- Dotenv
- Cors
